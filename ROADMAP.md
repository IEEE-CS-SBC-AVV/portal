# Roadmap

## Phase 1: Foundation ✅ (Complete)

- Next.js 16 static site with App Router
- TypeScript strict mode
- TailwindCSS v4 styling
- Content management via markdown files
- Committee member directory
- Event and news pages
- SEO, accessibility, security hardening

## Phase 2: Pre-Launch Polish ✅ (Complete)

- Contact form backend integrated with Formspree
- Image optimization via Next.js Image component everywhere
- Search functionality in navbar
- Member directory with filtering (/membership, /scope-members)
- SEO: unique metadata per page, sitemap, RSS feed
- Accessibility: WCAG AA compliant, focus traps, ARIA labels
- Performance: fonts via next/font, optimized images, framer-motion LazyMotion
- Structured data: Organization, Breadcrumb, Event JSON-LD
- Security: CSP, HSTS, X-Frame-Options, honeypot fields
- CI/CD: lint, type-check, build, test in pipeline
- Comprehensive accessibility audit (WCAG AA)
- Test suite (Vitest)
- Error boundaries consolidated via shared ErrorFallback

## Phase 3: Planned (Future)

- Supabase backend integration
- Admin dashboard for content management
- Image upload system
- Dynamic gallery with actual photos
- Analytics integration
- PWA support
